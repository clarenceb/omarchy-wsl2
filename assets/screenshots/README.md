# Screenshots

Images referenced from the top-level `README.md`. Committed deliberately —
unlike `assets/*.png`, these are hand-made, not regenerated by `make logo`.

## Naming

| File | Shows |
|---|---|
| `mode1-headless.png` | Windows Terminal running the Omarchy CLI |
| `mode2-wslg-apps.png` | A GUI app as an ordinary Windows window |
| `mode3a-nested.png` | The sway desktop nested in a WSLg window |
| `mode3b-vnc.png` | The desktop full screen over VNC |
| `wizard.png` | `./omarchy-wsl2` running |

## Guidelines

- **Capture on Windows**: `Win+Shift+S` for a region, `Win+Alt+PrtScn` for a
  single window. Nothing inside WSL can see the Windows desktop.
- **1600px wide is plenty.** GitHub renders README images at ~800px; anything
  larger just inflates the repo.
- **Compress before committing.** On Ubuntu:

  ```bash
  sudo apt install optipng pngquant

  optipng -o5 assets/screenshots/*.png          # lossless, ~40-60% smaller
  pngquant --quality=70-90 --ext .png --force \
    assets/screenshots/*.png                    # lossy, far smaller again
  ```

  Or with ImageMagick, which the image already ships, to resize and strip
  metadata in one pass:

  ```bash
  magick shot.png -resize 1600x -strip assets/screenshots/mode3a-nested.png
  ```

- **Prefer a dark theme** in both the terminal and the desktop so the shots sit
  well against GitHub's dark mode, which most visitors use.
- **Avoid personal detail**: check hostnames, paths under `/mnt/c/Users/...`,
  git remotes, tokens in scrollback and browser tabs before committing.

## Suggested composition

For the nested shot, the point to convey is that this is a real tiling desktop,
not just a terminal:

1. Snap Windows Terminal (Ubuntu, running `btop` or `fastfetch`) to the left
   with `Win+Left`.
2. `omarchy-wsl-desktop --size 1280x800`, then `Win+Right`.
3. Inside the session, open two or three terminals so the tiling is obvious —
   `fastfetch`, `btop`, `lazygit` all read well at small sizes.
4. The waybar pill bar at the top identifies it immediately; leave it visible.
